# Projetos em Desenvolvimento de Software

Este repositório é dedicado a projetos desenvolvidos em diversas linguagens de programação, com o objetivo de demonstrar habilidades técnicas em diferentes tecnologias. Os projetos foram planejados para serem claros, eficientes e aplicáveis a cenários reais.

## Estrutura do Repositório

O repositório está organizado com cada projeto em pastas separadas. Cada pasta contém os códigos-fonte, bem como qualquer material complementar, como README ou scripts necessários.

### Projetos Disponíveis

#### **Java**

1. **Sistema de Gerenciamento de Biblioteca**
   - Um sistema para gerenciar livros, usuários e empréstimos.
   - Funcionalidades:
     - Cadastro de livros e usuários.
     - Realização e finalização de empréstimos.
     - Relatórios para monitoramento de atividades.
   - **Tecnologias**: Java, Collections Framework, JDBC (opcional para persistência).

2. **Ferramenta de Automção para Renomear Arquivos**
   - Um utilitário para renomear arquivos em massa com base em regras configuráveis.
   - Funcionalidades:
     - Renomeia arquivos usando prefixos, sufixos e numeração.
     - Filtragem por extensão.
   - **Tecnologias**: Java, Manipulação de Arquivos (java.io e java.nio).

#### **JavaScript**

3. **Lista de Tarefas (To-Do List)**
   - Aplicativo simples para organização de tarefas diárias.
   - Funcionalidades:
     - Adicionar, editar e remover tarefas.
     - Marcar tarefas como concluídas.
     - Interface amigável baseada em navegador.
   - **Tecnologias**: JavaScript, HTML, CSS.

#### **Python**

4. **Sistema de Reservas para um Restaurante**
   - Sistema completo para gerenciar reservas em um restaurante.
   - Funcionalidades:
     - Cadastro de clientes e reservas.
     - Controle de disponibilidade.
     - Relatórios de reservas realizadas.
   - **Tecnologias**: Python, Orientação a Objetos.

#### **C#**

5. **Sistema de Reservas para um Restaurante**
   - Sistema completo para gerenciar reservas em um restaurante.
   - Funcionalidades:
     - Cadastro de clientes e reservas.
     - Controle de disponibilidade.
     - Relatórios de reservas realizadas.
   - **Tecnologias**: C#, Orientação a Objetos, Estruturas de Dados.

#### **SQL**

6. **Banco de Dados para Loja Online**
   - Estrutura de banco de dados relacional para uma loja virtual.
   - Funcionalidades:
     - Tabelas para usuários, produtos, pedidos e itens do pedido.
     - Relacionamentos entre as tabelas para integridade dos dados.
   - **Tecnologias**: SQL, Modelagem de Banco de Dados.

## Como Executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/cqemartins/Projetos_JAVA.git
   ```
2. Navegue até o diretório do projeto desejado:
   ```bash
   cd Projetos_JAVA/<nome_do_projeto>
   ```
3. Consulte o README de cada projeto para instruções específicas de execução.
